# SkillSwap

Платформа позволяет пользователям обмениваться навыками, создавая сообщество 
взаимного обучения.
Проект реализован как одностраничное приложение (SPA) на стеке на
**React + Redux + TypeScript + Vite**.

---
Используются моковые данные, которые расположены в папке **/public/db**.
Для наглядной демонстрации работы:
- по кнопке "Войти" происходит логин под случайным пользователем
- для простоты и наглядности сменить пользователя можно, кликнув по его аватару

---

## Быстрый старт

1. Подготовка:
    ```bash
    npm install
    ```

2. Запустите проект в режиме разработки:
    ```bash
    npm run dev
    ```

3. Если не открылась вкладка, откройте в браузере:
    👉 [http://localhost:3000/](http://localhost:3000/)
